# TENNISTRACK

A responsive tennis training and match journal built as a self-contained website.

## Run it

Open `index.html` in a modern browser, or serve this directory with any static web server. No build step or external service is required. Google Fonts are an optional enhancement; the site falls back to system sans-serif fonts if they are unavailable.

## Features

- Practice-session logging, editing, deletion, search, and court-surface filters.
- Match logging with win/loss summaries, editing, deletion, and history filters.
- Skill progression tracking for all requested categories.
- Daily practice goal and seven-day practice chart.
- Smart training recommendations based on saved data.
- Player profile name, local community journal, and export/reset tools.
- Responsive dashboard for desktop and mobile layouts.

## Data and privacy

Practice sessions, matches, skill levels, goal, player name, and community updates are stored in this browser using `localStorage`. They are not uploaded or synchronized and are not shared with other users. Clearing browser site data removes the journal. Community posts are visible only in this browser profile.
